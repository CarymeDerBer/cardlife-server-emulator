Сюда кладут свои JSON-ответы сервера (подхватываются сразу, перезапуск не нужен).

Имя файла = путь запроса, где "/" заменён на "_":
  /api/auth/login        ->  api_auth_login.json
  POST /api/lobby/join   ->  POST_api_lobby_join.json   (файл с методом в приоритете)

Папка responses/ содержит сохранённые запросы игры — по ним видно, какие пути и тела она шлёт.
Страница статуса при запущенном сервере: http://127.0.0.1:8080/_status
